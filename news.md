## Four DOS terminals with SESSIONS · 21 November 2026

Run [SESSIONS.EXE](applications.html#app-sessions) to open a DOS prompt and use Alt+Shift+F1 through F4 to move between four terminals. Leave an editor or a database open, run another application, and resume where you left off. Tab completes paths. Alt+Shift+F10 closes every terminal and returns to DOS.

[CODE](applications.html#app-code), [FLOW](applications.html#app-flow), [CMATH](applications.html#app-cmath), and [INTRO](applications.html#app-intro) were updated for workspace switching. All 16 DOS applications are available from [Applications](applications.html#applications).

## CPU benchmark · 20 November 2026

Run `CPU.EXE` in DOS to measure instruction throughput and get an approximate 486DX2-equivalent MHz reading. The test takes about one second and returns to the prompt. Download it from [Applications](applications.html#app-cpu).

## More responsive DOS controls · 20 November 2026

On supported DOS systems, releasing a held key cancels its queued auto-repeat before it reaches the application. This helps prevent extra deletions and cursor moves when the application is busy. CODE, BOARD, CALENDAR, EXPLORER, and FLOW also reuse their rendered workspace during menu navigation for faster response.

The eleven updated DOS packages are available from [Applications](applications.html#applications).

## BUDOSTACK for MS-DOS

In the age of AI finding time to actually utilize your brains can be
difficult. The pace of engineering and science is accelerating, and 
often in worklife one cannot anymore afford spending time to search, 
learn and memorize information like we used to do it. This can cause
our brains to evolve into direction from which science does not yet
have enough information.

BUDOSTACK is a collection of applications designed for MS-DOS with one
goal in mind: force the user to process and produce information without
the help of AI. Easiest way to get started is to download DOSBOX into
your preferred device, and install the BUDOSTACK application suite.

For maximum focus, we recommend setting up an environment without 
internet connection. An old desktop computer will work nicely for this
purpose. If possible, try using old 5:4 or 4:3 display - you might be
positively surprised!

Start with [WRITE](applications.html#app-write) to draft a manuscript, [FLOW](applications.html#app-flow) to diagram a process, or [EXPLORER](applications.html#app-explorer) to manage files in two panes.
