# BUDOSTACK website

This static site is published by GitHub Pages at [www.budostack.com](https://www.budostack.com/).

Edit `news.md` to update the News section. It accepts normal Markdown, including headings, lists, links, and fenced code blocks. The site loads it from the same directory as `index.html`.

To preview locally, run `python3 -m http.server 8000` in this directory and visit <http://localhost:8000/>.

The application listings in `index.html` point to screenshots in `screenshots/` and individual downloads in `releases/`.
