Installation

  1. Download an application ZIP and extract it into your DOS programs folder. Keep the folder structure inside the ZIP.
  2. On a DOS PC, open that folder or add it to your DOS PATH. In an MS-DOS emulator, mount the extracted folder as a drive. In DOSBox Pure, you can also open the ZIP directly.
  3. Type the program name at the DOS prompt. Use PROGRAM /? for command-line help.

Target system: 486DX2/66 MHz with MS-DOS and VGA. Downloads are free and include the application and its companion files. Supply your own licensed copy of MS-DOS if you install MS-DOS.
