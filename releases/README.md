# DOS application ZIPs

Follow the [release procedure](../README.md#release-a-commands-application) to update a download. Each ZIP contains the DOS executable at its root and any companion files in the corresponding application folder.

Each updated package records its COMMANDS commit in the ZIP comment. INTRO is the assembly build from COMMANDS commit `1be4c90eef220855f832f9d26a27de26166663a3`. Packages linked with the Open Watcom runtime include its license and source notice. FLOW and DBASE ship with generic examples prepared for the public catalog.
