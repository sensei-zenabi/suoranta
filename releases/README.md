# DOS application ZIPs

The initial catalog uses the ready-to-run DOS builds from COMMANDS `main` at commit `1be4c90eef220855f832f9d26a27de26166663a3`.

Each archive has the corresponding executable at its root. When COMMANDS ships an application subdirectory under `BUILD/`, keep the application subdirectory. The public FLOW and DBASE packages use site-specific backup and library examples. Preserve these examples when refreshing the executables. The ZIPs use deflate compression. Keep source files and development tools outside the archives. After updating a ZIP, update its displayed size in `index.html` and verify that the archive extracts correctly.

The screenshots show the distributed builds running in DOSBox Pure. They use the shipped sample data where relevant and example files or keyboard input for other use cases.
