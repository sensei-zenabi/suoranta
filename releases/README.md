# DOS application ZIPs

Follow the [release procedure](../README.md#release-a-commands-application) to update a download. Each application ZIP contains the DOS executable and `VERSION.TXT` at its root and any companion files in the corresponding application folder.

Each package records its version and COMMANDS commit in the ZIP comment. Packages linked with the Open Watcom runtime include its license and source notice. FLOW and DBASE ship with generic examples prepared for the public catalog.
