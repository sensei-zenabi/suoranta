# DOS application ZIPs

Follow the [release procedure](../README.md#release-a-commands-application) to update a download. Each ZIP contains the DOS executable at its root and any companion files in the corresponding application folder.

The initial catalog uses the COMMANDS build at commit `1be4c90eef220855f832f9d26a27de26166663a3`, shown as build date `2026.11.13`. Later releases record the specific COMMANDS commit in the archive comment. FLOW and DBASE include generic examples prepared for the public catalog.
